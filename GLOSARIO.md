## 📚 Comandos de Git

| Comando | ¿Qué hace? | Clase |
|---------|-----------|-------|
| `git init` | Inicializa un repositorio en la carpeta actual | 16 |
| `git status` | Muestra el estado de los archivos (modificados, nuevos, etc.) | 15 |
| `git add .` | Prepara todos los cambios para commit | 15 |
| `git commit -m "mensaje"` | Guarda los cambios con un mensaje | 15 |
| `git push` | Sube los commits a GitHub | 15 |
| `git clone URL` | Descarga un repositorio de GitHub a tu computadora | 05 |
| `git pull` | Descarga y fusiona los cambios más recientes | 15 |
| `git branch` | Lista las ramas locales | 16 |
| `git checkout -b rama` | Crea una rama nueva y se mueve a ella | 16 |
| `git checkout rama` | Se mueve a una rama existente | 16 |
| `git merge rama` | Fusiona los cambios de una rama en la rama actual | 16 |
| `git diff` | Muestra los cambios línea por línea | 15 |
| `git log` | Muestra el historial de commits | - |
| `git stash` | Guarda cambios temporalmente sin hacer commit | 17 |
