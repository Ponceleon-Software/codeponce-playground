# 🧪 CodePonce Playground

**Laboratorio Open Source de Ingeniería**

Bienvenido al playground de CodePonce. Este repositorio es el espacio práctico donde aplicarás todo lo que aprendes en la [App CodePonce](https://codeponce.app). No es un curso — es un proyecto real donde colaborarás con otros estudiantes.

```text
CodePonce App          →   Aprendés la teoría
       ↓
CodePonce Playground   →   Aplicás lo aprendido
       ↓
Pull Requests          →   Tu evidencia y portafolio
```

---

## 🚀 ¿Primera vez?

No empieces por aquí. Seguí este camino:

1. Completá las clases en la [App CodePonce](https://codeponce.app)
2. Las clases **00 a 07** te guían desde cero: qué es GitHub, fork, clone y tu primer PR
3. Cuando llegues a la **Clase 07** ("Tu primer flujo completo"), volvé aquí
4. Ahí ya sabrás qué hacer

> ¿Ya tenés experiencia con Git y GitHub? Leé [`CONTRIBUTING.md`](./CONTRIBUTING.md) y empezá a contribuir.

---

## 📚 Niveles

Cada nivel es una branch que agrega una tecnología nueva al proyecto.

| Nivel | Branch | Tecnología | ¿Qué aprendés? |
|-------|--------|------------|----------------|
| 1 | `level-1-fundamentos-html` | HTML | Estructura semántica, tablas, formularios, multimedia |
| 2 | `level-2-estilos-css` | CSS | Flexbox, Grid, responsive, animaciones, variables |
| 3 | `level-3-interactividad-js` | JavaScript | DOM, eventos, fetch, localStorage, dark mode |
| 4 | `level-4-tailwind` | Tailwind CSS | Utility classes, design tokens, dark mode variants |
| 5 | `level-5-react` | React | Componentes, props, estado, contexto, router |
| 6 | `level-6-api-integration` | APIs | Fetch, hooks, error boundaries, paginación |

Podés empezar en cualquier nivel. Si ya sabés HTML, saltá directamente a CSS.

---

## 🏆 Progreso

Cada nivel tiene un archivo `signatures/level-N.md`. Cuando completes un desafío y tu PR sea mergeado, agregás tu firma ahí. Al completar los 6 niveles, podés postularte como **Maintainer** del proyecto.
